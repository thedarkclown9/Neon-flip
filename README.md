⚡ Neon Flip: Cyber Dodger

A high-reflex arcade web game built from scratch using HTML5 Canvas, Vanilla JavaScript, and the Web Audio API. 

## 🎮 Features
- **One-Tap Mechanics:** Flip gravity with a single screen tap, click, or Spacebar press.
- **Dynamic Speed Scaling:** Velocity ramps up logarithmically as your score climbs.
- **Cyber Hangar:** Collect in-game energy orbs to unlock 5 custom ship designs and trails.
- **Pure Web Audio:** Procedurally generated synth sound effects without external audio assets.
- **Ad Hooks Ready:** Pre-built triggers for rewarded revives and double-orb ad views.

## 🚀 How to Run Locally
1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
